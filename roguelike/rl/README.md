# 強化学習（敵AI）

ゴブリンの行動を**表形式Q学習**で学習する。依存は numpy のみ（PyTorch等は不使用）。

## 使い方

```bash
# 学習（roguelike ディレクトリで。10万エピソードでも10秒程度）
python3 -m rl.train --episodes 100000

# 保存済み方策の評価だけ
python3 -m rl.train --eval-only
```

学習すると `rl/policy.npz` が保存され、**次のゲーム起動からゴブリンが学習済み方策で動く**。
ファイルを消せば従来のA*追跡に戻る（コード変更不要）。スライムは比較用にA*のまま。

## 全体の構造

```
ゲーム本編                          学習側（このフォルダ）
─────────────                      ─────────────────────
components/ai.py                   rl/train.py   学習ループ
  RLEnemy.perform()  ←─ policy.npz ─  rl/qlearning.py  Q学習（numpy）
    │                                  rl/env.py     アリーナ環境（reset/step）
    └── rl/obs.py（観測エンコード。学習と本番で同じ関数を共有）
```

- **rl/env.py**：9×9の小部屋で「ゴブリン vs プレイヤーbot」を1対1で戦わせる
  gym風環境。ダメージ計算・移動判定は本編の `actions.py` / `combat.py` を
  そのまま呼ぶので、学習した方策は本番ダンジョンでも同じ力学で動く。
  エピソードごとに 1〜6階相当の強さのゴブリンを抽選（本編の階層スケールと同じ式）。
- **プレイヤーbot**：隣接していてスタミナがあれば攻撃、なければ待機して回復、
  離れていれば接近（まれにランダム）。本編プレイヤーの単純化。

## 状態・行動・報酬の設計（rl/obs.py, rl/env.py）

| 要素 | 内容 | サイズ |
|------|------|--------|
| 相対位置 | プレイヤーとの dx, dy（±4に丸め） | 9×9 |
| 自分のHP | 比率を高/中/低の3段階 | 3 |
| 相手のHP | 同上 | 3 |
| 相手の臨戦 | プレイヤーが今攻撃できるか（スタミナ） | 2 |

状態数 1458 × 行動 9（8方向＋待機）。HPを**比率**で持つので、
階層スケールで強化された個体でも同じQ表が使える。

報酬：与ダメ +2/点、被ダメ −1/点、撃破 +30、死亡 −15、
1ターン −0.02、生き残り +5（値は `env.py` の `R_*`）。

## 学習で獲得された行動の例

- 自分のHPが低く、プレイヤーが攻撃可能 → **逃げる**
- プレイヤーのスタミナが切れている → **接近して殴る**
- 非隣接でプレイヤーが臨戦状態 → **待機**（無闇に近づかない）

つまり「スタミナ切れを狙うヒット＆アウェイ」の素地が出ている。
報酬の係数を変えると性格が変わる（攻撃的⇄臆病）ので、調整して再学習→
`--eval-only` やゲーム内で比較すると面白い。

## 報酬設計（現行・rl/env.py の R_*）

「攻めて削るほど得」になるよう設計（旧設計は生存ボーナス＋大きな被弾ペナルティで
“逃げ得”になり、敵が近づかなかった）：与ダメ +3/点・撃破 +40、被弾 −0.4/点・死亡 −6
（控えめ＝交戦を恐れない）、1ターン −0.3、**接近報酬**（プレイヤーへ1マス近づくと +1.2／
離れると同額減点）、生存ボーナスは廃止。

## 本番側の動き（components/ai.py の RLEnemy）— ハイブリッド

観測に『壁』が無くダンジョンの通路で詰まるため、**接近は A*（確実に回り込む）**に任せ、
**隣接した間合いだけ方策で「攻撃／後退／待機」**を決める。これで敵は必ず近づいて攻撃し、
HPやプレイヤーのスタミナを見た駆け引き（不利なら引く）が RL の担当として活きる。
方策が無ければ純粋な A* 追跡にフォールバック。`policy.npz` は起動後1回だけ読み込み、
全個体でQ表を共有（クラス属性なのでセーブデータには入らない）。同士討ちの気まぐれも従来通り。

## 群れ戦術（複数敵アリーナ）— rl/pack_env.py, rl/pack_train.py

1体では強いプレイヤーにまず勝てない（1対1の生存率0%）。**複数で囲めば勝てる**——
そこで「無闇に固まらず多方向から囲んで退路を断つ」連携を学習させる拡張。

```bash
# 群れ学習（ソロ〜3体を混ぜて学習し、ゲーム本編の policy.npz に保存）
python3 -m rl.pack_train --episodes 15000 --n-agents 3 --vary-agents --out rl/policy.npz
# 群れ方策 vs 突進ベースラインの比較だけ
python3 -m rl.pack_train --eval-only
```

- **PackArenaEnv**：N体のゴブリン vs プレイヤーbot。全ゴブリンが**同じQ表を共有**して
  各自 ε-greedy で動く（独立Q学習＝IQL＋パラメータ共有）。撃破報酬は群れ全員に入る＝連携が得。
- **観測に「最寄り味方の方向」を追加**（obs.py・v2）。これが無いと各個体が1対1流の
  臆病な間合い取りをして群れでは突進に負ける。味方方向を見ると囲み・連携が学べる。
- **キティングbot**：プレイヤーは「2体以上に囲まれたら逃げる」。開けた部屋で全員突進だと
  逃げ道が空くので、多方向から囲む連携が要る。この相手で群れQは突進を明確に上回る
  （例：勝率 71% vs 63%、平均生存 1.7体 vs 1.1体）。
- 本番反映：`RLEnemy` は `encode(self, target, allies)` に他の生きた敵を渡す（隣接間合いの
  駆け引きが味方考慮に）。接近は従来どおり A*（壁対策）。

## オンライン学習（プレイヤーの実戦から随時適応）— rl/online.py

同梱の `policy.npz`（基本方策）はそのまま出荷用の“初期値”とし、**ゲーム内では
その複製に対して実戦の遷移で Q を更新**して、今のプレイヤーの戦い方に適応する。

- **OnlineLearner**（rl/online.py）：基本方策のコピーを持つ共有Q表。`Engine` が1つ
  保持し、Engine まるごと pickle されるので**セーブに入る**。学習率 α=0.05 と小さめ＝
  適応は緩やか＝挙動が暴れない。基本方策は**読み取り専用**（複製を学習）。
- **リセット条件（“新しいデータ”＝新しいプレイ）**：ニューゲームは `Engine.__init__` で
  `OnlineLearner.new_default()`（基本方策コピー）から開始＝自動でデフォルトに戻る。
  観測設計（POLICY_VERSION）が変わった古いセーブも、`savegame.load_game` でリセット。
  同じセーブの続きなら適応を保持する。
- **学習する遷移**：RLEnemy が方策で判断する「隣接間合いの駆け引き」だけ（接近は A*＝
  方策外なので学習しない）。敵はグリーディに動き（探索なし）、実戦の (s,a,r,s') で
  off-policy 更新。報酬は学習時と同じ係数（rl/online.py の R_*）。撃破（+R_KILL）は
  その一手を即確定、被撃破（+R_DEATH）は combat._die の `on_death` フックで確定。
