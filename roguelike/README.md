# Roguelike（仮）

Python + [pygame](https://www.pygame.org/) で作る、風来のシレン系ローグライク。
将来的に **敵AIへ強化学習を導入**し、**Steam公開**を目指す。

## 必要環境

- Python 3.9+
- 依存ライブラリ：`pip3 install -r requirements.txt`（pygame, numpy）

## 実行

```bash
python3 main.py
```

**解像度はタイトルの「画面設定」から選べる**（1280×720 / 1600×900 / 1920×1080 / 2560×1440）。
いずれも 16:9 で、タイル64pxがちょうど並ぶように下部パネル高を自動調整するので**ドット等倍でぴったり**収まる。
選んだ解像度は `settings.json` に保存され次回も引き継ぐ。`F11` で全画面（`pygame.SCALED` が整数倍に拡大）。
村の建物内など画面より小さいマップは中央寄せで表示する。

## 操作

| キー | 動作 |
|------|------|
| 矢印キー / WASD / hjkl | 移動（攻撃モード中はその方向へ攻撃） |
| Z | 足踏み（1ターン待機。スタミナ回復にもなる） |
| Space | 移動モード ⇄ 攻撃モード 切替 |
| G | 足元のアイテムを拾う（要らなければ拾わず通過できる） |
| i | 持ち物を開く（メニュー中は ←→で分類切替、↑↓でカーソル移動、Enter で使用/装備、i/ESC で閉じる） |
| t | スキルツリーを開く（←→系統・↑↓段・Enter習得・t/ESC閉じる） |
| Enter / > / < | 足元の階段で昇降（下り階段→次の階／上り階段→前の階。1階の上り階段→村へ帰還） |
| F5 / F9 | セーブ / ロード（階層・持ち物・畑・倉庫・開放区画も保存） |
| F11 | 全画面 ⇄ ウィンドウ |
| ESC | 終了 |

拠点（テント内）では方向キーで移動、設備の上で Enter、ESC でダンジョンに戻る。

ゲームは**森の外れの寂れた村**から始まる。NPCに話しかけ（隣で Enter）、北の**洞窟**（Enter）からダンジョンへ。
村には**道具屋・武器防具屋・食料品店・民家**があり、各**ドアの上で Enter**すると別マップ（建物内）に入れる
（建物内では出口ドアか ESC で村へ戻る）。店主の隣で Enter すると**買い物**ができる。

**お金＝経験値**。買い物の代金は所持金（＝ためた経験値）で支払い、足りない分は**レベルダウン**して捻出する
（レベルが下がると最大HP・攻撃力も下がる）。装備で今すぐ強くなるか、経験を貯めてレベルで伸ばすかの駆け引き。
パネルの「所持金」が使える総経験値。

**スキルツリー**（`t` で開く）：9系統（攻撃・防御・運・料理・農業・漁業・酪農・錬金・魔法）×3段。
レベルアップで**スキルポイント**を得て解放する。各系統は下の段から順に。効果は攻防の上昇、運=会心、
料理/農業/漁業/酪農/錬金/魔法はそれぞれの効率アップ。**レベルダウンすると、下がった先のレベル時点の
スキル構成に戻る**（お金＝経験値を使うとここも巻き戻る）。再びレベルを上げればポイントは戻り、付け直せる。

**下り階段**（寒色・▼）で次の階へ、**上り階段**（暖色・▲）で前の階へ戻れる（Enterで昇降）。
潜入中は各階が保持され、行き来しても同じ地形・敵・探索状況のまま。**1階の上り階段から村へ帰還**できる
（村に戻るとダンジョンはリセットされ、次の潜入は新しい地形）。深い階ほど敵が増える。
地形は階層でテーマが変わり、**浅層（〜3階）は洞窟**、深層は石になる。壁は床に面した側だけ
縁取りして塊が**連結**して見え、床は壁際に影が落ちて境界が分かりやすい（`assets/gen_tiles.py`）。

各階の最初の部屋は**セーフルーム**（床の色が違う）。**モンスターは入れず**、
**テントはここでのみ使える**。階段はセーフルームには出現せず、セーフ化でフロアが
分断されない（生成時に連結を検証）。

アイテムの上に乗ると右下に `足元: ○○（G で拾う）` と表示。**G で拾う**（要らなければ通過）。持ち物は12個まで。
持ち物画面は **消費／素材／武器／防具／大切なもの** の5分類タブ。

**魔法のテント**（大切なもの・セーフルームでのみ使用可）を使うと、**歩けるテント内（拠点）**に入る。
方向キーで歩き、設備の上で **Enter** で利用、**ESC** でダンジョンに戻る（拠点内は時間が止まる）。

- **住居区画**：**収納**（倉庫に預ける/取り出す）、**料理（かまど）**、**アイテム錬金**
- **畑区画**：4区画の畑。区画の上で植える/状態確認/収穫（**歩数**で成長）
- **牧場区画**（鍵で開放）：牧柵に動物（ニワトリ→卵 / ウシ→ミルク）を入れ、歩くと産物が育ち**繰り返し収穫**
- **漁業区画**（鍵で開放）：**釣り**（エサを消費して魚/大魚/フグ＝要調理）、**養殖**（いけすで魚を増やす）
- 区画は `牧場の鍵`/`漁業の鍵`（ダンジョンドロップ）を「使う」と開放。卵・ミルク・魚などは料理の食材

**料理**：鍋に任意の食材を入れ、調理法（生/焼く/煮る/蒸す）を選ぶ。食材ごとの**栄養素**
（たんぱく質→攻撃 / ミネラル→防御 / ビタミン→HP / 炭水化物・脂質→満腹度）の合計×調理法×入れすぎ補正で
効果が決まる。**毒性が高いと食中毒**で逆効果。食べると満腹度＋一時バフ。数値は `cooking.py`。

素材→（栽培）→食材→（料理）→効果付き料理、という流れ。

**満腹度**は毎ターン減り、0になると**空腹**＝攻撃の消費スタミナ1.5倍・被ダメージ1.5倍。
食料（木の実・携帯食料）を食べて回復する。
持ち物メニューは **↑↓ でカーソルを動かし Enter で使用/装備**（`[装備中]`表示）。
パネルの「攻撃／防御」は装備ボーナス込みの実効値。
**攻撃の消費スタミナは 武器＋防具** で決まる（重い武器・重い防具ほど消費大）。
軽装＝手数・低防御／重装＝高防御だが攻撃が重い、というトレードオフ。
ST表示の `(-N)` が1回の攻撃で消費する量。

攻撃は**スタミナ**を消費する（攻撃1回 = 30、最大100）。足りないと攻撃できず、
移動・足踏みなど攻撃以外のターンで回復（+10/ターン）。数値は `components/fighter.py`。

## 画像素材・フォント

`assets/` に PNG を置くと自動で読み込む。無いものは仮タイル（単色）で代用。
必要なファイル名は [assets/README.md](assets/README.md) を参照。

UIフォントは同梱の **PixelMplus**（ドット絵調の日本語フォント・M+ライセンス）を使用。
`assets/fonts/game.ttf` を置くと差し替えられる（PixelMplus が無い環境ではヒラギノ等にフォールバック）。

## モジュール構成

| ファイル | 役割 |
|----------|------|
| `main.py` | 起動・メインループ（pygame） |
| `engine.py` | ゲーム状態の保持・ターン処理の司令塔 |
| `graphics.py` | 描画（カメラ追従・タイル画像の読み込み） |
| `input_handlers.py` | pygame入力 → Action への変換 |
| `entity.py` | プレイヤー/敵/アイテムの共通クラス（テンプレート複製対応） |
| `entity_factories.py` | 敵・プレイヤーの定義集（ステータス調整はここ） |
| `actions.py` | 行動（移動・攻撃・ぶつかり判定）をデータとして表現 |
| `tile_types.py` | 床・壁・ドア・木などタイルの定義 |
| `village_map.py` | 村（屋外）マップ：建物・ドア・森・洞窟入口 |
| `buildings.py` | 家・店の内部マップと店主の定義 |
| `shop.py` | 店の品揃えと購入処理（代金＝経験値） |
| `skills.py` | スキルツリー（9系統×3段・レベル毎スナップショット/復元） |
| `game_map.py` | マップ配列とエンティティの保持 |
| `procgen.py` | ランダムダンジョン生成・敵配置 |
| `pathfinding.py` | A*経路探索・Bresenham（純Python実装） |
| `components/ai.py` | 敵の頭脳（A*追跡AI と 学習済み方策で動く RLEnemy） |
| `components/fighter.py` | 戦闘ステータス（HP・攻撃力・防御力） |
| `rl/` | 強化学習（環境・Q学習・学習スクリプト）。詳細は [rl/README.md](rl/README.md) |

## 強化学習

**ゴブリンはQ学習で学習した方策で動く**（スライムは比較用にA*のまま）。

```bash
python3 -m rl.train --episodes 100000   # 学習して rl/policy.npz を更新（約10秒）
python3 -m rl.train --eval-only          # 保存済み方策の評価
```

- 方策ファイル `rl/policy.npz` が無ければ従来のA*追跡に自動フォールバック
- 状態・行動・報酬の設計、環境の仕組み、次の発展は [rl/README.md](rl/README.md) を参照
- 差し替え地点は `components/ai.py` の `RLEnemy`（観測±4マス内でQ表、遠距離はA*）
