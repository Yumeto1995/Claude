# Claude Chat 用：画像生成プロンプト集

## ★キャラ高精細化・ワンショット版（これだけ貼ればOK）

**`player.png` `npc.png` `goblin.png` `slime.png` `corpse.png` の5枚を添付**して、以下を丸ごと貼る：

```
あなたは熟練のピクセルアーティストです。添付した5枚は、2Dローグライク
（風来のシレン風・見下ろし3/4視点）で現在使用中の 32×32 キャラクタータイルです。
これらを市販のドット絵ゲームと遜色ない品質に「描き直し」てください。

【守ること】
- 実寸 32×32 ピクセル。アンチエイリアス・ぼかし禁止
  （大きく描く場合は 512×512 で「1ドット=16×16ブロック」厳守、最近傍縮小で劣化しないこと）
- 背景は完全透過。ファイル名は元と同じ5つ。ダウンロードできる PNG で出力
- 各キャラの主要色とシルエットは維持（今までの画面と見比べて「同じキャラ」と分かること）
- 5枚で頭身（2頭身）・アウトライン（暗色1px）・彩度・光源（左上）を統一
- 足元はタイル下端から2〜3px空ける（ゲーム側で影と跳ねるアニメが付くため）

【品質の上げ方（市販品質の条件）】
- 明暗3〜4階調の面で立体を作る（ベタ塗り＋1ハイライトで終わらせない）
- 色数はキャラあたり8〜12色。隣接色相を使った豊かな陰影（紫がかった影など）
- シルエットの輪郭に表情を付ける（髪の房、服のはためき、装備の出っ張り）
- 顔は目を大きく1〜2pxのハイライト。32×32でも感情が読めること

【各キャラの方向性】
1. player.png — 若い剣士。青い服＋茶髪は維持しつつ、マント・ベルト等のディテール追加可
2. npc.png — 穏やかな村人。緑〜茶系の落ち着いた服
3. goblin.png — 緑肌の小鬼。ずる賢い表情と棍棒。敵らしい攻撃的シルエット
4. slime.png — 青いゼリー。透明感（内部の気泡・芯）とぷるぷる感のハイライト
5. corpse.png — 倒れた灰色の亡骸＋骨。床になじむ控えめな彩度
```

> できた PNG を `assets/` に上書き → ゲーム再起動で反映。
> 気に入らない1枚は「◯◯だけ、△△の方向でもう一度」と追加指示すると良い。

Claude Chat に貼り付けて、ゲーム用タイル画像（PNG）を生成してもらうためのプロンプト集。

## 使い方

1. 新しいチャットを開き、最初に **「共通スタイルガイド」** を貼る
2. 続けて、作りたいカテゴリの **バッチプロンプト** を貼る（1チャット1バッチ推奨。全部一度に頼むと品質が落ちやすい）
3. 既存画像を洗練させたい場合は、**現在の PNG を添付**して「リファイン指示」を併用する
4. もらった PNG をこの `assets/` フォルダに上書き保存 → `python3 main.py` で見た目を確認

> Claude Chat が画像を直接生成できない場合は、末尾の「フォールバック指示」を足すと
> Pillow スクリプトとして受け取れる（手元で `python3 gen.py` を実行してPNGを得る）。

## 共通スタイルガイド（毎回最初に貼る）

```
あなたは熟練のピクセルアーティストです。2Dローグライクゲーム
（風来のシレン風・見下ろし3/4視点・レトロJRPG調）のタイル画像を作ってください。

【共通仕様・厳守】
- 1枚ずつ、指定したファイル名の PNG としてダウンロードできる形で出力する
- 実寸 32×32 ピクセルのドット絵。アンチエイリアス・ぼかし・グラデーションは禁止
  （大きく描く場合は 512×512 で「1ドット = 16×16 の正方形ブロック」を厳守し、
   最近傍法で 32×32 に縮小しても一切にじまないこと）
- キャラクター・アイテム・設備は背景を完全透過（アルファ0）にする
- 床・壁・階段などの地形は不透過で、32×32 の全面を使う
- パレットは DB32（DawnBringer 32色パレット）に統一。1枚あたりの実使用色は 6〜10 色
- 輪郭：暗色 1px のアウトライン。光源：左上。影：右下に1段暗い色
- 最優先事項：32×32 でもシルエットだけで何か判別できること。
  細部の描き込みより「形の特徴」と「明暗のコントラスト」を優先する
- 雰囲気：明るめの正統派ファンタジー。かわいすぎず、レトロJRPG（スーファミ後期）調
- 複数枚を依頼したときは、全枚で頭身・線の太さ・彩度を揃えて統一感を出すこと
```

## 既存画像のリファイン指示（画像を添付して使う）

既存の画像を洗練させたい場合は、共通スタイルガイドのあとにこれを貼り、**現在の PNG を添付**する：

```
添付したのは現在ゲームで使っている 32×32 のタイル画像です。
これを上の共通仕様で「描き直し」てください。条件：

- 主要な色とシルエットの特徴は維持すること
  （プレイヤーが今までの画面と見比べても「同じもの」と認識できること）
- その上で、陰影・アウトライン・形の整理を改善し、ドット絵として洗練させる
- ファイル名は元と同じにする

改善の観点：
- アウトラインが途切れている／太さが不揃いな箇所を直す
- 明暗2〜3段の階調で立体感をつける（光源は左上）
- 32×32で見たときにつぶれている細部は、思い切って省略して形を大きく
```

> 一度に添付するのは1バッチ分（4〜5枚）まで。バッチ単位で頼むと統一感が保たれる。

## バッチ G：攻撃ポーズ（3枚・透過）※ゲーム対応済み

`<キー>_attack.png` を置くと、攻撃モーション中だけ自動で差し替わる（コード変更不要）。
通常画像（player.png 等）を**添付して**から、これを貼る：

```
添付したのは 32×32 のキャラクタータイルです。それぞれと完全に同じキャラ・配色・
頭身・アウトラインで、「攻撃の瞬間」のポーズ差分を作ってください。

1. player_attack.png — player.png の差分。剣を振り抜く／突き出すポーズ。
   体は少し前傾。武器の軌道が分かる形に
2. goblin_attack.png — goblin.png の差分。棍棒を振り上げ／振り下ろすポーズ
3. slime_attack.png — slime.png の差分。体当たりの瞬間。体が進行方向に
   ぐにゃっと伸びた形（スライムらしい変形で攻撃を表現）

共通条件：
- 頭の位置・体の中心は元画像から大きくずらさない（差し替え時にガタつかないように）
- 攻撃している感じはポーズ（シルエットの変化）で出すこと。エフェクト線は描かない
  （斬撃エフェクトはゲーム側で別途描画される）
```

## （参考）歩行アニメ用フレームについて

現在の歩行・攻撃アニメは **1枚のスプライトをコードで動かす方式**（スライド＋ホップ）なので、
**追加のフレーム画像は不要**。

将来「足が動く」コマアニメにしたくなったら、
`player_walk1.png` / `player_walk2.png` のような2フレーム（左足前／右足前）を用意し、
`graphics.py` の `MoveAnim` でフレームを切り替えるコード変更が必要になる。
そのときのプロンプト：

```
player.png（添付）と完全に同じキャラ・配色・頭身で、歩行アニメ用の2フレームを作ってください。
1. player_walk1.png — 左足を前に踏み出したポーズ
2. player_walk2.png — 右足を前に踏み出したポーズ
体の輪郭・頭の位置は固定し、足と腕だけ動かすこと（2枚を交互に表示して歩いて見えること）
```
