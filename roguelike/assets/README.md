# 画像素材（assets）

ここに PNG 画像を置くと、ゲームが自動で読み込みます。
**無いものは仮タイル（単色）で代用**されるので、描けたものから順に追加できます。

## 必要なファイル名

| ファイル名 | 用途 |
|------------|------|
| `player.png` | プレイヤー |
| `goblin.png` | ゴブリン |
| `slime.png` | スライム |
| `corpse.png` | 倒した敵（死体） |
| `floor.png` | 床 |
| `wall.png` | 壁 |

## 仕様

- 形式：**PNG**（透過対応。キャラは背景を透明にすると重なりが綺麗）
- サイズ：自由（読み込み時に `TILE_SIZE`＝32px へ自動拡縮）。
  最初から 32x32 で描くと拡縮の劣化がない。
- タイルサイズを変えたいときは `graphics.py` の `TILE_SIZE` を変更。

新しい敵やアイテムを増やすときは、`entity_factories.py` の `sprite="..."` と
同じ名前の PNG をここに置き、`graphics.py` の `PLACEHOLDER_COLORS` にも追加する。
