# 高画質アセット生成プロンプト集（現行設計対応）

Claude Chat などに貼って、ゲーム用のドット絵（PNG）を**市販品質**で作らせるためのプロンプト集。
生成物を各フォルダに置けば、ファイル名＝キーで自動読み込みされて反映される。

> これは「本番画像」用。**簡易プレースホルダは `gen_sprites.py`／`gen_tiles.py`／`gen_items.py`** が
> プログラム生成する（差し替え前の仮画像）。本ファイルは旧 `PROMPTS.md` の散在バッチを、
> 現行のフォルダ構成・手続き的アニメ設計に合わせて作り直したもの。

---

## ★設計の前提（生成前に必ず読む）

- **動き（歩行の跳ね・攻撃の踏み込み・静止の呼吸）は `graphics.py` の手続き的モーションが付ける。**
  よって **キャラは「方向別のベース1枚」だけで動く**。歩行コマ（`*_walk1/2`）や攻撃ポーズ（`*_attack`）は
  **任意の上乗せ**で、置けば `_resolve` が自動採用する（無くても手続き的モーションで動く）。
  → まずは**各キャラ 4方向のベース画像だけ**を高品質で作れば十分。
- 画像は **ファイル名＝キー**で読み込まれる（`load_sprites` がサブフォルダ再帰）。
  下表の**名前・フォルダ・サイズ**を守れば、上書きコピーするだけで反映される。
- **サイズ**：キャラ＝**64×64**／アイテム・設備・地形＝**32×32**（64へ整数2倍でくっきり表示）。
- **透過**：キャラ・アイテム・設備・木/ドア等は**背景透過**。床/壁のシームレス地形は不透過。
- **右向きは自動ミラーしない**（刀・盾が逆手になるため）。`*_right` も用意する
  （左右対称に近いデザインなら `*_left` の水平反転でも可）。

### 反映先フォルダ（キー接頭辞→フォルダ）
| キー例 | フォルダ |
|--------|----------|
| `player_*` | `characters/player/` |
| `npc_*` | `characters/npc/` |
| `goblin_*` | `monsters/goblin/` |
| `slime`, `boss` | `monsters/slime/`, `monsters/`（任意。再帰読込なので場所は自由） |
| `corpse`, 各アイテム | `items/` |
| `st_*`, `farm_*` | `structures/` |
| 地形（`*_floor`/`*_wall`/`grass`/`tree` 等） | `backgrounds/<テーマ>/` |

## 共通スタイルガイド（毎バッチの先頭に貼る）

```
あなたは熟練のピクセルアーティストです。見下ろし3/4視点・レトロJRPG（スーファミ〜GBA後期）調の
2Dローグライク用ドット絵を、市販ゲームと遜色ない品質で描いてください。

【厳守】
- 1枚ずつ、指定ファイル名の PNG としてダウンロード可能な形で出力
- 実寸は指定サイズ（キャラ=64×64／アイテム・地形=32×32）。アンチエイリアス・ぼかし・
  グラデーション禁止。大きく描く場合も「1ドット=正方形ブロック」を厳守し、最近傍縮小で
  一切にじまないこと
- キャラ・アイテム・設備は背景を完全透過（アルファ0）。床/壁の地形は不透過で全面シームレス
- パレットは DawnBringer 32（DB32）に統一。1枚の実使用色は 6〜12 色
- 光源は左上、影は右下に1段暗い色。輪郭は暗色1pxのアウトライン
- 最優先：小さくてもシルエットだけで何か判別できること（描き込みより形と明暗のコントラスト）

【品質を上げる条件（市販品質）】
- 明暗3〜4階調の面で立体を作る（ベタ塗り＋1ハイライトで終わらせない）
- 隣接色相を使った豊かな陰影（紫がかった影など）
- シルエットに表情を付ける（髪の房・布のはためき・装備の出っ張り）
- 複数枚は頭身・線の太さ・彩度・光源を全枚で統一
```

## バッチ1：キャラクター（方向別ベース）※最優先

各キャラ **down / up / left / right の4方向ベース1枚ずつ**（64×64・透過・2〜2.5頭身）。
**歩行/攻撃のコマは不要**（コード側でモーションを付けるため）。足元はタイル下端から2〜3px空ける。

必要ファイル：
- `player_down.png` `player_up.png` `player_left.png` `player_right.png`
- `npc_down.png` `npc_up.png` `npc_left.png` `npc_right.png`
- `goblin_down.png` `goblin_up.png` `goblin_left.png` `goblin_right.png`
- `slime.png`（無方向）／`corpse.png`（無方向）／`boss.png`（大型・後述）

```
以下のキャラクターを、共通仕様で「4方向（正面=down / 背面=up / 左向き=left / 右向き=right）」
各1枚、計セットで作ってください。64×64・背景透過・2〜2.5頭身のデフォルメ。歩行や攻撃の
コマは不要（静止ポーズ1枚ずつ）。4方向で同一人物・同一配色に見えること。

1. player（プレイヤー）— 若い冒険者/剣士。茶の短髪、緑のチュニック、赤いマント、
   小さな丸盾と剣。明るく目を引く配色で「自分の操作キャラ」と一目で分かること。
2. npc（村人）— 穏やかな年配の村人。緑〜茶系の落ち着いた服。player と混同しない配色。
3. goblin（ゴブリン）— 緑肌の小鬼。とがった耳、ずる賢い表情、粗末な棍棒。敵らしい攻撃的な印象。

各キャラ down/up/left/right の順で、ファイル名は例：player_down.png … player_right.png。
right は left の鏡像で構わない（装備が左右非対称なら描き分ける）。
```

無方向キャラ（1枚ずつ・別チャット可）：
```
1. slime.png — 半透明の青いゼリー状の丸い体。内部の気泡と芯、ぷるぷるのハイライト。表情は目だけ。64×64・透過。
2. corpse.png — 倒した敵の亡骸。灰色のシルエット＋小さな骨。床になじむ暗め・低彩度。64×64・透過。
3. boss.png — 「ゴブリンロード」。goblin を大型化した王。豪華な兜/マント/大剣。3×3マスに拡大表示されるので
   ディテールは大きめに。堂々とした威圧的シルエット。64×64・透過（ゲーム側で3倍表示）。
```

> （任意の作り込み）動きをコマでも表現したくなったら、`player_left_walk1.png` `player_left_walk2.png`
> `player_left_attack.png` … を同じ命名で足すと自動採用される。無理に作らなくてよい。

必要ファイル：`potion` `scroll` `scroll_confuse` `dish`

## 反映手順（生成物 → ゲーム）

1. **単色背景（白など）で1アイコンずつ出させる**と切り抜きやすい。
2. 透過・トリム・64×64化：`IN=<入力> OUT=<出力> python3 _icon.py`（四隅から背景判定→縁flood-fillで透過→中央64化）。
3. 目視後、上表のフォルダへコピー（ファイル名＝キーのまま）。ゲーム再起動で反映。
4. **方向別を1枚のシートで生成**した場合は `SHEET=... DIR=down python3 _slice_dir.py`（1方向ずつ切り出し）。
5. headless 確認：`SDL_VIDEODRIVER=dummy python3 -c "..."` で `Renderer.render(Engine(80,50))` を数フレーム回して
   `pygame.image.save(r.screen, ...)`（GUIウィンドウは開けない環境のため）。
```
